# Как вернуться к проекту

Краткая шпаргалка: что это, как запустить и где что лежит.

## Что это

Практическое занятие 2 по курсу «ИИ в урбанистике»: анализ кварталов **Иркутска**
библиотекой **BlocksNet**. В ноутбуке считаются землепользование, население, школы,
обеспеченность, плотность, типы застройки и доступность. Отдельный скрипт собирает
из готовых результатов интерактивный `dashboard.html`.

## Быстрый старт

```bash
cd "/Users/ekaterina/03_Учеба/ИТМО/ИИ в урбанистике/python-package-boilerplate"
source .venv/bin/activate

# 1. Пересобрать дашборд из уже посчитанных данных (без скачивания и расчётов)
python dashboard.py

# 2. Открыть его через локальный сервер (так подгружаются тайлы карты)
python -m http.server 8000
# затем в браузере: http://localhost:8000/dashboard.html
```

Ноутбук открывается в VS Code: `notebooks/practice_02.ipynb` → выбрать ядро
`.venv (Python 3.11.2)` → **Run All**. Все результаты пишутся в `data/` в корне проекта.

## Как это устроено

- **Ноутбук** — единственное место, где что-то считается. Последняя ячейка каждого
  этапа сохраняет GeoJSON в `data/` и перечитывает его для проверки.
- **`dashboard.py`** — ничего не считает и не скачивает. Просто читает `data/*.geojson`
  и `provision_links.csv`, рисует карту (folium) и графики (matplotlib), собирает HTML.
  Поэтому его можно перезапускать сколько угодно — данные не изменятся.
- Тяжёлые кэши (`graph_walk.pkl`, `accessibility_matrix.csv`, `*_raw.geojson`)
  удалять не нужно: без них повторный запуск ноутбука снова пойдёт в OSM.

## Если что-то пошло не так

- **Карта пустая / нет подложки.** Открывайте через `python -m http.server 8000`,
  а не двойным щелчком по файлу: некоторым тайлам нужен `Referer`.
- **Ноутбук в VS Code показывает старое содержимое.** Файл изменился на диске:
  `Cmd+Shift+P` → **File: Revert File**, либо закрыть вкладку без сохранения и открыть заново.
- **Ошибка Overpass / `JSONDecodeError`.** Сервер OSM перегружен. В ячейке настройки
  уже прописаны зеркала и повторы — просто перезапустите ячейку. Граф также кэшируется
  в `data/graph_walk.pkl`.
- **`KeyError: "['building'] not in index"` или `['site_area', ...]`.** `impute_*`
  в BlocksNet удаляет лишние колонки. Нужные поля сохраняйте в отдельную переменную
  **до** вызова `impute_buildings` / `impute_services` (в ноутбуке это уже сделано).
- **`land_use` странного вида.** Это Enum; перед графиками выполняется
  `x.value if hasattr(x, "value") else x`.
- **Ядро не видно.** `Cmd+Shift+P` → **Developer: Reload Window**, затем выбрать
  `.venv (Python 3.11.2)`.

```bash
# активировать окружение
source .venv/bin/activate

# проверить, что ноутбук не повреждён
python -c "import nbformat; nbformat.validate(nbformat.read('notebooks/practice_02.ipynb', as_version=4)); print('ok')"

# пересобрать дашборд и узнать размер
python dashboard.py && ls -lh dashboard.html

# посмотреть, какие результаты уже есть
ls -lh data
```

## Git

Результаты в `data/` намеренно **не кладём в git**: файлы большие (~70 МБ) и
восстанавливаются запуском ноутбука. Они остаются на диске локально. В историю
сохраняем код, ноутбук и гайд:

```bash
git add -A -- . ':(exclude)data'
git commit -m "practical-02: notebook and dashboard"
```

Сырые выгрузки, `graph_walk.pkl` и `accessibility_matrix.csv` дополнительно
исключены через `.gitignore`.
